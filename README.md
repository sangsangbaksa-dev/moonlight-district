# 달빛 상권

실시간 도시 경영 및 상권 경쟁 게임. 작은 상점에서 시작해 두 AI 기업과 상권을 경쟁하며 도시를 건설합니다.

## 플레이

- 지도에서 인접한 상권을 선택해 골드로 확보하거나, 경쟁 회사의 상권을 영업력으로 인수합니다.
- 상점·주거시설·홍보소·학교·라운지·공장·병원·놀이공원을 지을 수 있습니다. 상권이 늘어날수록 시설이 열립니다.
- 상점을 포함한 시설을 선택한 뒤 **건물 입장**을 누르면 3D 내부에서 직원을 고용할 수 있습니다. 직원 효과와 급여는 정산에 반영됩니다.
- 상점에서는 14가지 상품을 개발하고 판매할 수 있습니다. 인기 상품과 지형에 맞는 상품은 매출이 늘어납니다. 상점은 물자를 소비하고 공장은 물자를 생산합니다.
- 수입, 영업력, 물자와 병력은 6초마다 정산됩니다. 도시 계약을 달성하면 보너스를 받습니다.
- 상권 18곳부터 군사 훈련소가 열립니다. 훈련한 병력으로 인접한 경쟁 상권에서 전투할 수 있습니다.
- 상권 40곳, 주거시설 2곳, 서로 다른 기반시설 3종을 갖추거나 경쟁 회사의 본점을 모두 인수하면 승리합니다. 본점을 빼앗기거나 AI 기업이 상권 40곳을 확보하면 패배합니다.
- 지도에서 확대·축소할 수 있으며, WebGL이 없는 브라우저에서는 평면 지도로 전환됩니다. 진행 상황은 브라우저에 저장됩니다. 다른 창으로 이동하면 게임이 일시정지됩니다.

## 개발

Node 22 이상. `npm ci`, `npm run dev`, `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`.

도시 규칙은 `src/territory.ts`, UI는 `src/city.ts`, 도시와 건물 내부의 3D 렌더링은 `src/cityMap.ts`에 있습니다. 이전 서바이벌 프로토타입 코드는 별도로 남아 있지만 현재 진입 화면에는 사용하지 않습니다.
