# 달빛 상권

실시간 도시 경영 및 상권 경쟁 게임. 작은 상점에서 시작해 두 AI 기업과 경쟁하며 도시를 확장합니다.

## 플레이

- 11×11 지도에서 인접한 상권을 골드로 확보하거나, 경쟁 상권을 영업력으로 인수합니다. 환승역을 지으면 두 칸 떨어진 상권에도 진출할 수 있습니다. 지도는 드래그와 확대·축소가 가능합니다.
- 상점, 주거시설, 학교, 공장, 병원, 놀이공원, 물류 창고, 연구소 등 시설을 건설합니다. 건물 내부에서 직원을 고용하거나 시설을 3단계까지 강화할 수 있습니다.
- 상점에서 14가지 상품을 판매합니다. 인기 상품과 상권 적합도에 따라 매출이 달라지고, 상점이 소비하는 물자는 공장과 창고에서 공급합니다.
- 시청에서 유통·산업·도시계획·안전·군사 연구를 진행하고 정책을 선택합니다. 정책에는 이점과 비용이 함께 있습니다.
- 도시 현안에 대응하고, 지정 상품을 판매하며 물자를 모아 특별 납품을 완료할 수 있습니다. 도시 계약은 단계별 보상을 줍니다.
- 경쟁사에 45초 휴전을 제안하거나 상권 18곳부터 군사 훈련소를 열 수 있습니다. 출병 시 기습·정규 진군·포위 작전 중 하나를 선택하며, 도착 시간과 병력 손실이 다릅니다. 진군 중 목표가 바뀌거나 방어가 강화될 수 있습니다.
- 동네 상권, 산업 도시, 광역 도시, 도시 연합의 네 단계 목표를 순서대로 달성하면 승리합니다. 승리 후에도 도시를 계속 운영할 수 있습니다. 경쟁 속도는 여유·보통·도전 중 선택합니다.
- 진행 상황은 브라우저에 저장되며 기존 9×9 저장은 11×11 지도로 이전됩니다. 다른 창으로 이동하면 일시정지됩니다. WebGL이 없는 환경에서는 평면 지도를 사용합니다.

## 개발

Node 22 이상. `npm ci`, `npm run dev`, `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`.

도시 규칙은 `src/territory.ts`, 저장 이전은 `src/save.ts`, UI는 `src/city.ts`, 3D 지도와 건물 내부는 `src/cityMap.ts`에 있습니다. 이전 서바이벌 프로토타입은 현재 진입 화면에 사용하지 않습니다.
